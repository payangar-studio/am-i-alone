# Where companions live

Not designed yet.

## In game

Companions appear without owner in the world: in village taverns, and sometimes
in structures. A player meets them there and can make one their own.

## How it is built

Not designed. What is known: an unowned companion is an ordinary entity saved
with its chunk, with no anchor (`../companion/01-entity.md`), so a structure
can hold several at the cost of villagers.
