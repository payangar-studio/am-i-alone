Companion debug stick

Scaffolding, designed with the inventory

An item to test what has no interaction in the game yet. Each of its actions is removed once the real interaction exists.

In game

An item, the companion debug stick, that only operators can use: in anyone else's hand it does nothing. It is obtained by /give only, in no creative tab. It looks like vanilla's debug stick, glint included; its name tells them apart.

How it is built

  1. The companion is asked first and does not answer.
  2. The companion debug stick gets the click next.
  3. On the server, an operator gets the companion's inventory screen; anyone else gets nothing.
Decision"Operator" is the gamemaster permission, the one vanilla's debug stick checks (Permissions.COMMANDS_GAMEMASTER, Player.java:1823-1825), without vanilla's creative mode requirement, so it can be tested in survival. It is checked on the server.
DecisionThe item handles the click itself (Item.interactLivingEntity); the companion knows nothing of it.
FactA companion does not consume a right-click, so the item gets it: Player.interactOn asks the entity first, then the item (Player.java:806-842), and neither LivingEntity, Avatar nor Companion answer it (Entity.java:2317-2389).
DecisionThe item has no texture of the mod: its client item definition (assets/am_i_alone/items/debug_stick.json) points to vanilla's debug stick model (minecraft:item/debug_stick), and the item carries enchantment_glint_override, as vanilla's does (Items.java:2416-2423).
